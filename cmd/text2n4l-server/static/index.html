How to Use

  1. Paste your text in the left panel (Input Text area)
  2. Adjust the selection percentage if needed (default: 10%)
  3. Click "Process Text" to analyze the content
  4. Review the generated N4L content in the right panel
  5. Edit the N4L output as needed for your Promise Theory analysis
  6. Use the "Copy" button to copy the final result

About N4L Format:

N4L (Narrative for Learning) format extracts high-intentionality sentences that are significant for knowledge representation and Promise Theory analysis. The algorithm identifies sentences with both dynamic running assessment and static post-hoc assessment techniques.
