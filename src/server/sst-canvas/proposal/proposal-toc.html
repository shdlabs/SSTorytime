Command Specifications

sst search - Semantic Search 
sst search [QUERY] [OPTIONS]

Examples:
  sst search "whale"                    # Basic search
  sst search "whale" --context "moby"   # Context search  
  sst search --regex "ship.*"           # Regex pattern
  sst search --node 42,7                # Direct node access
  sst search --interactive              # Interactive mode
  sst search --limit 10                 # Limit results
  sst search --format json              # Output format

Options:
  --context TEXT    Search within context
  --regex          Enable regex patterns  
  --limit N        Maximum results
  --format FORMAT  Output: text|json|html
  --node ID        Direct node reference
  --interactive    Interactive search mode
sst export - Generate Deliverables 
sst export [FORMAT] [OPTIONS]

Examples:
  sst export js --output viz.html       # Standalone HTML
  sst export json --compress            # Compressed data
  sst export package --target mobile    # Mobile-optimized
  sst export js --include-data          # Embedded data
  sst export html --template custom     # Custom template

Options:
  --output FILE     Output filename
  --compress        Enable compression
  --target TYPE     Optimization target
  --template NAME   Use template
  --include-data    Embed all data
  --size-limit SIZE Maximum size
sst compile - Knowledge Processing 
sst compile [INPUT] [OPTIONS]

Examples:
  sst compile story.txt                 # Process text file
  sst compile --format n4l examples/   # Process N4L files
  sst compile --watch --auto-export    # Watch mode
  sst compile --source dir/ --output knowledge.json

Options:
  --format FORMAT   Input format: txt|n4l|md
  --output FILE     Output filename
  --watch          Watch for changes
  --auto-export    Auto-generate exports
  --source DIR     Source directory
